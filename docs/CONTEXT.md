# 字幕封装助手 (mux_ui) — 领域术语表

本文件只记录已定术语，不含实现细节。

## 核心概念

- **封装 (mux)**：用 mkvmerge 把视频 + 字幕轨道 + 字体附件合成一个 MKV 文件的过程。
- **字幕轨道 (subtitle track)**：封装进 MKV 的字幕。语言固定：简体 = zh-Hans，繁体 = zh-Hant。**简体存在时是默认轨道**；只给繁体时繁体自动成为默认轨道。
- **轨道命名 (track name)**：用户为简/繁字幕轨道指定的显示名称，默认 SC / TC。
- **字体子集化 (font subsetting)**：assfonts 从字体目录中提取字幕实际用到的字形，生成子集字体并嵌入 MKV，保证播放器不缺字。
- **字体体检 (font check)**：封装前检查字幕用到的字体在字体目录中是否齐全，列出缺失字体（含「字体存在但缺字形」），避免封装到一半才发现。
- **编码转换 (encoding conversion)**：检测字幕文件的编码（GBK / BIG5 / UTF-16 / UTF-8 含 BOM），非 UTF-8 时生成 UTF-8 转换副本用于后续流程，**不改动原文件**。GBK 与 BIG5 字节重叠产生歧义时按繁体特征字判定，仍无法判定则提示用户确认，**不静默转换**。
- **预览帧 (preview frame)**：用 ffmpeg+libass 渲染视频指定时间点的一帧（字幕烧录其上），供肉眼检查字体、字号、竖排等效果；SRT 字幕先按默认样式转为 ASS 再渲染；**支持内封字幕轨**（预览时自动抽取所选轨道与视频自带字体附件，PGS 图形字幕除外）。
- **批量任务 (batch job)**：多个封装任务排队串行执行，逐个报告成功/失败；提交时校验输出路径，同名冲突则拒绝提交并列出冲突项。
- **任务项 (batch item)**：批量任务中的单个组合 = {视频, 简体字幕(可选), 繁体字幕(可选)}。

## 拖放识别

- **拖放识别 (drop resolution)**：把拖入窗口的文件名在扫描根内定位成完整路径的过程。
- **扫描根 (scan root)**：拖放识别搜索的目录，默认 `D:\Video`，可在「高级选项 → 工作目录」更改并持久保存；也是文件浏览器的默认起点（服务启动时后台预建文件名索引，定期刷新）。索引覆盖扫描根内全部目录（工具自身目录除外），不按目录名排除用户目录。**首次启动**（未配置或配置失效）时强制引导设置工作目录，可跳过（拖放识别暂不可用，之后可随时补设）。
- **定位失败 (unresolved drop)**：拖入的文件不在扫描根内时，界面显示红色"未找到"提示，并自动打开文件浏览器让用户手动选择。

## 路径与输出

- **文件浏览器 (file browser)**：服务端目录浏览弹窗，用于选择本地路径（视频/字幕/字体目录/音轨/输出目录）。
- **输出目录 (out dir)**：封装结果输出位置。留空 = 直接替换源视频，原件备份到视频旁的 `__mux_tmp_manual`。
- **替换 (replace)**：无输出目录时的默认行为；输出成功后原文件移入备份目录，新文件占用原名。备份目录内同名冲突时自动加序号/时间戳，**永不覆盖已有备份**。

## 轨道选择 (2026-08-26)

- **轨道选择 (track selection)**：在 ① 查看轨道 中勾选要保留的源音轨 / 源字幕轨；视频轨必须保留（锁定）。选择结果分别传给封装：保留的音轨 ID 列表、保留的源字幕轨 ID 列表、是否保留源附件。
- **音频模式 (audio mode)**：① 中源音轨勾选的三种结果：全选 = 保留全部源音轨；全不选 = 去掉全部源音轨；部分 = 仅保留勾选的源音轨。外部音轨（④）与音频模式**正交**：无论 ① 如何勾选，外部音轨总是追加进输出。
- **保留源附件 (keep attachments)**：勾选则保留源 MKV 的字体/封面附件；不勾选则丢弃并用新子集字体重建；**无外部字幕（没有新子集字体可重建）时自动保留源附件**。
- **封装进度 (mux progress)**：从 mkvmerge 日志中解析"进度: N%"百分比，单任务与批量任务均显示进度条。
- **音轨卡片定位**：④ 只负责外部音轨文件（+ 语言/名称）；源音轨取舍一律在 ① 完成；两者正交组合，互不覆盖。
