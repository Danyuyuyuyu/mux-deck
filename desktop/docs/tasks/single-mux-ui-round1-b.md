## 输入、输出与边界

输入：A 已审查通过的状态与接纳接口、当前 Avalonia 窗口和现有单任务 Core。

输出：实际可操作的新封装页、三个拖入接收区、统一选择器接线、详情与结果操作、更新后的 UI 验证及本次截图/报告。

失败行为：无效拖入或选择保留原配置，失败原因出现在可见的 `InteractionMessage`；异步选择/分配/确认结束后提交再次检查编辑锁与修订。平台打开/复制错误同样可见。任务成功、取消或失败只依据 Core 结果。

主要文件归属：Views（可合理拆为 UserControl）、`App.axaml`、必要的 `MainWindowViewModel` 展示接线、Desktop 内的小型平台操作/输入呈现帮助类、相关 Smoke 和 `RealUiAcceptance.cs`、`README.md`/`skeleton.md` 对应操作与新控件说明。允许为明确的展示需求对 A 文件作最小补充，必须保留接纳语义并通过 A 行为检查；额外 API 合同变化先报告负责人。

Core、进程/诊断政策、包版本、v1、批量和字体预检保持现有实现。本轮复用已有控件即可，不因表格引入新的付费或第三方控件。

## 页面实现

- “封装 / 字体附件”是可见页签；日志 Tab 以明确开发模式开关控制，Debug 默认显示、Release 默认隐藏。Release 仍有结果诊断详情和日志操作，不需要新增配置持久化。
- 顶部为视频摘要和选择/更换按钮，空态说明可拖入 MKV/MP4。主内容显示文件名及可靠媒体信息，完整路径在详情/Tooltip 中可查看并可复制；长中文文件名正确截断，键盘用户也能获取完整路径。
- 媒体时长呈现为可读的时分秒；允许新增派生展示属性，不改变底层探测数据。尺寸/时长未知则省略，不用文件扩展名补猜容器。
- “轨道与内容”内源/外加两组共享列布局，SourceTracks 与 ExternalTracks 分别使用正确投影；源策略显示“保留/移除”且只读，外加行 IsIncluded 表示是否进入输出。禁用行仍能查看和编辑属性，并明确标记暂不加入。
- 源附件折叠成数量与移除策略，展开时使用 SourceAttachments；主表不逐条塞附件。源视频/音轨不出现可操作的保留开关。
- Inspector 支持展开/关闭，小窗口可折叠或下置。名称/default/forced 可编辑，仅针对外加字幕；语言固定只读。使用模型 `CanEdit` 和行 `CanEdit`，源旗标未声明显示未声明。
- “添加 ASS 字幕”按钮、行更换/移除和勾选可用；SC/TC 仍最多两槽。列表行选择与复选框/按钮事件互不误触，支持键盘、明确焦点和可访问名称。
- 字体目录、输出目录和输出文件名集中在封装页下部，目录完整路径可查看/复制。字体选择按钮与字体页选择操作一致；主摘要显示“封装时检查”，字体页只做目录和当前真实能力说明。
- 底部固定状态与操作区，正文可滚动。准备、运行、取消清理、取消、失败、成功、成功附提示均有正确呈现；处理阶段无来源的百分比不显示，原始工具文本只在详情/日志中出现。
- 使用 State/StateSummary 表达当前状态，ResultLabel 区分上次结果；Result 原始 Error、Checks、Warnings 在可展开详情保留，成功提示不能因日志 Tab 隐藏而消失。
- 成功显示输出文件名/位置以及“打开文件位置 / 再次封装”；失败可重试和查看诊断。每种状态只有一个突出主操作，运行时取消可用，取消清理中提示等待并防重复操作；当前草稿修改后主区回到草稿状态。
- 支持复制源/字幕/目录路径、输出位置和诊断；支持打开实际成品所在位置及现存日志。平台操作用精确路径和参数传递，不将路径拼进 shell 命令。空路径或目标消失给出可见原因。
- 延续现有深色主题资源，统一边距/行高/按钮层级，无需动画或主题重构。保持环境检测页面可用。

## 拖入与选择器接线

使用本项目 Avalonia 12.1.2 的真实 API，先核对已安装 API/官方文档；不要直接套旧版拖放示例。

1. 视频摘要、外加内容和字体目录分别注册接收；拖入悬停高亮并说明动作。视频区仅单个 MKV/MP4，ASS 区仅 1–2 个 ASS，字体区仅单文件夹。
2. 从系统文件数据取得本地文件/文件夹候选；文本、URL、非本地项目不能包装为 Local 候选。读取与拒绝不写草稿，不读取媒体内容或触发 AFS。
3. 使用 A 的 Prepare→确认→Commit。一次 ASS 拖入/选择使用一个分配对话框明确 SC/TC，默认优先空槽但由用户确定；所有候选与替换摘要可见。双文件操作一次提交，取消时全部保留原样。
4. 同槽更换已明确槽位，可走单候选 Prepare；替换已有异路径视频/ASS 须明示确认。避免同一操作弹出两个内容重复的确认框，可在分配框中完成明确替换确认。
5. 同步收紧视频文件选择过滤器与提示为 MKV/MP4；选择器与拖入使用同一接纳接口。字体/输出目录选择分别使用 PrepareFontsDirectory/PrepareOutputDirectory；输出目录本轮只通过按钮选择。
6. 拒绝混合文件、超量、重复、错误类型与不存在路径，保留原输入并展示原因。拖放 Effects 与高亮遵守可接纳状态；离开/取消/关闭对话框/处理完成清理高亮。
7. 操作进行中防止重叠分配/确认流程；运行、取消清理、关闭等待停止接纳，异步返回后仍交 Commit 复核。不以 IsEnabled 或悬停检查代替提交守卫。

## 同路径重新探测边界

按 A 审查记录补最小状态处理和行为检查：成功后同路径重探测失败不能把旧轨道/附件/摘要当作当前结果；外加字幕和设置保留。实现可在探测开始清源数据或在失败时清掉，明确读取中状态；旧探测迟到保护与关闭等待保持。无须新增媒体文件监控。
