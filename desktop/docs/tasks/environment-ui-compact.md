# 环境与组件紧凑列表

## 本轮范围

只调整环境页布局和展示投影，检测、组件分类、状态计算、目录选择、恢复默认、保存路径与任务路径行为保持不变。

输入是现有 EnvironmentViewModel 的组件集合和管理展开状态；输出是限宽的紧凑总览、整行管理入口和共用组件条目。保存错误仍显示原始 SettingsMessage，不新增安装或更新能力。

## 布局

- 删除右侧共用页面标题，左侧导航负责页面定位。
- 总览只显示环境状态、最后检测、重新检测和一行核心/扩展统计。
- 内容左对齐，最大宽度 960 DIP；较小窗口自动缩窄，滚动条旁保留空隙。
- 管理入口整行可点击，常态无边框，Hover 使用极浅背景；展开后标题仍为“组件管理”，箭头表达展开状态。
- 两个目录用标签和用途说明区分，长输入保持单行编辑，恢复默认与保存路径靠右。
- 核心/扩展共用条目模板，状态列宽 104 DIP。名称、用途、单行版本/来源、子工具状态和路径建立层级。
- 缺失组件省略版本/来源，保留缺失原因；部分缺失仍展示子工具状态。
- 路径使用 caption、muted 与日志字体，省略显示并用 Tooltip 保留完整值。
