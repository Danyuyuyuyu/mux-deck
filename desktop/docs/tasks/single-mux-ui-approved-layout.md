## 1. 普通封装与空间预算

- 保留当前侧栏与深色资源，顶部标题/Tab 采用原型中的紧凑密度。视频摘要两行，完整路径、复制和重新探测收到明确的详情/次级入口；探测失败和输入拒绝依然可见。
- 1040×760 headless 应用内容区中，主内容宽约 828；摘要约 72 高、内容区约 312 高、设置约 118 高、固定状态约 76 高。以原生控件测量为准可微调，需说明偏差及原因，不通过缩小到难读字号伪装符合。
- 主页普通 3 源轨 + SC/TC 场景无需整体滚动，字体/输出设置与主操作同时可见。更多轨道仅清单内部滚动，源/外加分组共用一份选择状态；附件详情不使设置持续被推到屏外。
- 主表列为包含、类型、名称、格式、语言、默认。源/外加通过分组表达，分组标题仅“外加内容”。整行的主要区域可选择/打开属性；删除重复详情/更换/移除按钮，将外加操作移到 Inspector。
- 首列统一包含状态：源视频/音频勾选并只读，源字幕不勾选并只读，外加字幕可切换。使用按源策略生成的展示投影，不能直接绑定默认 true 的源行 IsIncluded。只读源行仍可选中；包含不同于 Matroska 轨道 enabled 旗标。
- 添加入口“＋ 添加轨道”，菜单“字幕（ASS）”可用、“音频（尚未支持）”禁用；继续走固定 SC/TC 两槽分配与 A 的 1–2 条 ASS 接纳，不扩展 Core 支持范围。
- 附件为轻量行“源附件（数量） / 本次不保留”，零附件时省略；查看入口仍能取得真实附件清单。
- 字体/输出目录并排，每项选择/打开和 `···` 次级菜单；复制路径保留在可见菜单，右键可作为补充。路径可截断但完整路径能由键盘查看/复制；输出文件名一行独立可编辑，拒绝覆盖规则保持。

## 2. 两个 Overlay Inspector

- 右侧 Track Inspector 默认宽 320，贴主内容右侧，覆盖摘要/清单/设置右侧，底部结束在状态栏上缘，内容溢出时仅面板内部滚动。包含、名称、固定只读语言、default/forced、来源/媒体信息、复制路径和外加文件更换/移除按图布局。
- 源轨属性按真实能力只读；外加可编辑属性和启用行为保持 A 合同；运行、取消清理、关闭等待时继续锁定。没有实际帧率等字段就省略，不用示意值补齐。
- 底部 Result Inspector 默认高 300，从固定状态栏上缘向上覆盖主内容；当前结果概览、Checks、Warnings、原始错误和日志/诊断操作集中在这里。失败/成功附提示在主状态区有简明摘要和详情入口，不直接把长原始错误塞入页脚。
- 两面板暂互斥：打开一个时关闭另一个，保留轨道选择和草稿；切换轨道原位更新右侧面板；关闭时恢复先前主清单滚动位置。配置修改后旧结果依然明确标为“上次结果”。
- 主布局不重排，状态与开始/取消/结果等主要操作不被面板覆盖。点击空白不自动关闭；× 和 Esc 可关闭；结果详情按钮可开关结果面板。暂不做动画、面板拖拽调高或双面板同时展示。
- 面板打开与焦点移入协调，关闭后回到触发入口/原选中轨道；Esc 先交内部菜单/下拉处理，再关闭面板。Tab/方向键可操作；避免焦点落入被面板遮住的控件。可见轨道名称/包含区域仍支持切换，面板内拖入不能穿透到底下的接收区。
- 名称修改按现有即时生效规则，关闭不是撤销；替换/移除继续使用现有确认、接纳、修订和编辑锁，图中的按钮不是新的业务入口。
- 底部状态面临长错误/提示或运行消息时可合理调整高度/提供详情，确保文本与主操作可达且不横向溢出；常见准备/成功状态优先遵循图中密度。

## 3. 数据真实性与 B-fix

- 原型电影名、QC 类别、附件数字全部替换为真实数据。当前 Result.Checks 为文本集合，本次可做逐项、分区的视觉呈现，不能解析中文/日志关键词拼出不存在的结构化成功证据。
- 无真实结果来源的成品计数/附件数先省略或显示尚未取得。若用现有 ProbeAsync 只读补成品摘要，必须绑定成功 Result 的输出快照并保护迟到结果；探测失败只影响摘要，不把已成功的 Core 结果改成失败，不使用新草稿的源探测/启用数量冒充上次成品。
- 原始 Error、全部 Checks/Warnings、次数及日志入口保留；成功附提示在 Release 隐藏开发日志后仍可发现。失败阶段/原因只显示已知信息；无来源的 68% 或精确错误码不加入。
- 合并 B-fix：无论行由按钮、ListBoxItem 或其他原生控件承载，实际可访问名称须辨认 SC/TC 及动作/轨道。不能为了旧测试保留隐藏名称按钮，不能让 peer 返回 StackPanel 类型文本。
