## 2. Overlay 键盘避让（F3）

- 为两个面板建立一致的焦点/键盘规则，打开后 Tab 和 Shift+Tab 不进入被遮挡的主控件，也不能在遮挡处编辑或启动输入动作；若打开时焦点将被遮住，应移到可用面板入口。
- 处理结果面板盖住的轨道行及轨道面板盖住的右侧操作/设置，不能只修复示例 OutputNameInput。指针命中测试、拖入不穿透继续成立。
- 可见清单名称/包含区域仍能切轨，固定状态/开始/取消/结果入口仍可操作；关闭恢复正常导航。不要将整个页面禁用或把非模态 Overlay 改成模态对话框。部分遮挡的复合区域采用明确、可验证的规则，不让焦点指向不可见的可编辑部分。
- 回归必须从正常入口打开面板后发送真实 Tab/Shift+Tab，检查聚焦控件与遮挡关系；不得每一步强制 Focus 目标后声称 Tab 导航通过。开/关、轨道↔结果、运行/取消锁定均检查。

## 3. 关闭恢复与轨道方向键（F4/F5）
