# 拖放自动识别与多轨封装

## 用户确认范围

修复 Windows 文件拖放误报；文件格式优先于同时携带的文本/URL 表示，纯文本和远程 URL 不作为本地文件。封装工作区任意可见位置支持自动识别、混合批次和自动落位，详情浮层不穿透。保留源视频替换确认。

用户进一步确认多字幕及 SRT：字幕不再受两个槽位限制，新增内容按添加顺序显示数字 ID、空名称留空。ASS 保留完整字体子集化/QC；SRT 不依赖字体工具，使用同工具参考往返校验全文。外加音频按探测得到的真实 Track ID、编码、语言和音频属性导入并封装，检查属性及原始数据校验。已有 SC/TC 接纳 API 保留其原契约，用于已有草稿和回归；新的拖放/添加入口不要求手工分配槽位。

## 接纳与失败行为

扩展名只用于快速悬停预判；落下后用 mkvmerge 探测容器，MKV/MP4 等按实际视频/音频轨判断，ASS/SRT 验证真实字幕类型。整个批次先准备，保持草稿不变；无效类型、多个源视频、重复路径/轨、多个字体目录、探测失败、确认取消、迟到或任务锁定时整批不提交。字幕/音频追加，不自动覆盖旧外加内容；更换已有轨道继续显式操作。字体文件落到其所在目录，文件夹作为字体目录，输出目录仍显式选择。

任务快照包含所有启用字幕/音频；源 A/V 固定保留，源字幕/附件移除，不更改既有失败/取消/不覆盖策略。仅 ASS 要求字体目录和字体后端；SRT 或音频可独立作为外加内容。

## 验收

- 文件+文本+URL 伴随格式正确接纳，纯文本/URL 拒绝，文件列表完整保留。
- 视频/多 ASS/SRT/多音轨/字体跨区域与混合拖入、重复/部分损坏批次原子拒绝，取消替换不改变旧草稿。
- 未知/带脚本的语言提示可回退 und；实际源语言保留，空名字留空；运行/取消/关闭锁定和迟到保护。
- 所有源/外加列宽、选择、独立纳入、详情更换/移除及焦点回归。
- 真实短素材：SRT-only、audio-only、多 SRT、多 ASS、ASS+SRT+audio；成品轨/flags/提取内容/音频 raw 数据、源哈希、冲突/取消与失败不发布。
- 原生 Explorer 拖放及 DPI 与 headless 证据分开记录。

## 实施结果

2026-10-10：本范围已实现，未增加依赖。Release 构建无告警/错误，自动导入 UI 25/25、真实新增封装 37/37、完整真实工具链 121/121、真实 UI 39/39，以及既有 UI/输入/工作台/告警回归通过；详细证据见[验证记录](../agents/verification.md#自动拖放与多轨封装2026-10-10)。多音轨容器与音频元数据/数据篡改反例均覆盖。字幕目前支持 UTF-8 ASS/SRT，不将其他格式视作已支持。

未人工操作 Explorer 原生拖放、系统选择器与 DPI；headless 模拟文件及伴随格式证明接纳流程，真实工具证据证明封装结果，两者不等同于原生拖放验收。
