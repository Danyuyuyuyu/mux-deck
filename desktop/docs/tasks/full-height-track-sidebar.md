输入：用户 2026-10-10 红框参考，范围从系统标题栏下方直到窗口底部，贴窗口右边缘。

输出：300 宽、无外侧留白与圆角的全高轨道属性覆盖栏，固定标题/关闭与外加轨道操作，中间单独滚动。单个封装主内容保留原位置与尺寸，结果详情仍使用现有底部面板，两面板互斥。
