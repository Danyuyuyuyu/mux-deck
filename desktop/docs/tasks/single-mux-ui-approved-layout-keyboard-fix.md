## 输入、输出、范围

输入：当前互斥非模态 Overlay、目录通知/固定槽路径通知、行重建焦点恢复和方向键导航。

输出：面板内操作可达、被遮主操作不可达、可见窗口导航仍可达，以及未选字幕变更时源轨选择保持；通过完整真实键盘遍历和绑定断言验收。

允许修改 `SingleMuxView.axaml.cs`、必要的局部 XAML、`SingleMuxViewModel.cs` 和相关 Smoke/helper；文档仅同步事实。不改 Core、诊断、包配置、主题、MainWindow 几何、v1；无需重新实现已验收的路径/方向键修复。

## G1–G3：统一实际可达性，保持窗口级导航

- 活动 Inspector 自身及其后代不是“被自己遮挡的底层控件”。结果面板打开后，Tab/Shift+Tab 能到关闭、复制路径、复制诊断、日志及可见文本操作；轨道面板内操作也保持可达。
- 两种 Overlay 对其下方主控件使用一致的遮挡规则。轨道面板盖住的 AddTrackButton/附件入口必须退出键盘输入；结果面板盖住的设置/行也退出。保留可见轨道名称/包含、状态开始/取消/结果等操作。滚动清单应依据可见部分处理，不能将裁剪外或滚动后被遮操作带入焦点。
- 不将 Tab 限制在 SingleMuxView 的自定义循环。可见 MainWindow 侧栏仍能从页面 Tab/Shift+Tab 到达并按原行为导航；通过既有窗口导航机制或等价的窗口级路径避让遮挡，尊重正常 Tab 顺序，不要求修改 MainWindow 布局。
- 面板开/关/切换和运行锁定后规则仍一致；不把整页禁用、不改成模态窗口、不回退指针/拖入防穿透。保持已有 ×/Esc 与行重建恢复能力。

## G4：用当前源身份保留选择

- 仅替换/增加/移除未选的外加字幕时，源轨选择保持同一源视频、类型/轨道身份，Inspector 路径保持该源视频；源行对象重建时解析到当前对象，不能依赖旧引用仍在列表。
- 外加 SC/TC 固定身份继续保留，真正移除所选轨道才走合理回退。更换源视频仍按既有规则清空旧选择，不能用相同数字 Id 误继承另一个视频的选择。
- Inspector 标题、字段、路径、选中状态与当前真实行一致。展示重建不增加草稿修订，成功 Commit 仍只按现有原子规则增加一次；未确认/拒绝输入保留原配置与选择。

## 自动化与出口

补足能在当前版本失败的行为断言，至少包括：

1. 从实际 ShowResultButton/轨道行打开面板，完整正向与反向 Tab 循环，结果关闭/复制/日志等动作都曾可达；不能只断言单步未到 OutputNameInput。
2. 完全被轨道面板盖住的添加/附件按钮不进入循环，不触发其输入动作；可见行与固定状态动作仍可达。
3. 两面板打开时页面可 Tab/Shift+Tab 到侧栏，页面切换按原行为保持草稿/结果，关闭后正常导航恢复。
4. 普通和多轨滚动场景验证焦点对应实际可见部分；不在每一步强行 Focus，也不依赖某个偶然落点控件名代替完整可达集合。
5. 选中源视频/音频行，只替换未选 TC/SC（走 Prepare→确认→Commit），源选择和实际 Inspector 路径保持；更换源视频不继承旧源身份。
