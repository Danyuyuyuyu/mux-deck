# 任务 A：第一轮状态与输入接纳接口

建议执行模型：`gpt-6.1-sol`，推理强度 `high`。先阅读 [第一轮合同](single-mux-ui-round1.md)、`desktop/AGENTS.md` 及其按任务链接的架构、开发与验证说明。

## 输入、输出与边界

输入：当前 `SingleMuxViewModel`、`TrackRowViewModel`、现有单任务 Core 与 Smoke。

输出：供任务 B 使用的摘要、分组、字幕启用、草稿/结果状态和输入接纳接口，以及有意义的行为检查。现有窗口在任务 A 完成后仍能构建、运行和封装；本任务不改页面布局，不接原生 DragDrop 事件。

失败行为：接纳失败返回可展示的原因且不改变原输入；任务提交及取消继续使用 Core 结果；界面消息不靠解析 stdout/stderr 判断成败。

允许修改：

- `src/MuxDeck.Desktop/ViewModels/SingleMuxViewModel.cs`。
- `src/MuxDeck.Desktop/ViewModels/TrackRowViewModel.cs`。
- 按需要新增 Desktop 内的小型输入接纳类型；展示/接纳逻辑不放入 Core。
- `tests/MuxDeck.Smoke/` 的独立行为检查文件及 `Program.cs` 最小接线；可补强现有 `UiSingleMuxContractChecks.cs`，保留已有验证。
- `docs/agents/skeleton.md` 中与本任务实际状态/接口有关的说明。

Core、Views、主题、包配置与 v1 保持当前内容。具体属性/方法名称由你设计，完成时给出供 B 使用的签名与语义，不预建通用框架。

## 实现内容

1. 暴露视频文件名、完整路径、可靠媒体摘要、探测状态与源附件数；保留旧 `Tracks` 兼容现有视图，并给新视图提供源轨道和外加字幕分组。源附件供数量/详情展示，不成为可编辑轨道；全源 A/V 保留，源字幕/附件移除。
2. SC/TC 外加字幕增加“包含在本次输出”的状态；禁用后保留路径和属性，依旧可查看。支持按槽位移除/替换。提交仅包含启用的字幕；零条启用时 `CanStart` 与 `StartCommand` 均不可执行。
3. 初次/组合变化的 SC/TC 默认规则保持现有行为；同槽替换和暂时禁用/启用保留显式名称与 default/forced。本轮语言仍只读、固定为 SC/TC。已有可设置多个/零个默认轨的行为保持，不顺便新增限制。
4. 给任务 B 提供接纳候选和确认后提交的接口：单视频、指定槽位 ASS、一次 SC/TC 分配、字体文件夹。视图从系统数据读取路径并完成用户分配/替换确认，ViewModel 接纳已明确的请求。所有接纳接口提交时再查 `CanEdit`。
5. 先检查整个输入操作再更改字段。只接受本轮支持的本地路径、类型、数量和唯一性；比较 Windows 绝对路径及大小写，避免在多文件操作中先写入 SC 再因 TC 无效返回失败。重复与同路径无害操作遵循第一轮合同。
6. 接纳和文件选择失败用独立、可观察的交互消息表达，保留正在显示的任务结果；字体目录选择只说明封装时检查。
7. 区分草稿配置与提交配置对应的结果，输入/启用/输出/外加字幕元数据变化均使旧结果成为“上次结果”；导航、选中轨道、展示切换不算配置变化。可以使用轻量修订号或等价实现；不清空 Core 结果以丢掉诊断和日志。
8. 提供当前真实状态摘要、进度阶段/消息和上次结果标记，供 B 布局使用。`CanStart` 只表示当前提交条件齐全，文件/字体/工具最终验证仍由 Core 完成。探测失败可见；不新增字体预检、虚构容器字段或百分比。
9. 正确维护属性变更通知和事件订阅生命周期；替换/移除/重建列表不累积订阅。任务快照不依赖之后可变的 ViewModel。保持已有取消、关闭等待与迟到探测保护。

保留 `VideoPath`、`ScSubtitle`、`TcSubtitle`、`FontsDirectory`、`OutputDirectory`、`OutputFileName` 等现有接线。旧直接属性赋值继续作为程序内部配置方式，文件类型/存在性接纳检查在新增接口执行；最终任务输入由 Core 复核，不用改变旧 Smoke 假路径场景来掩盖回归。字幕启用等新接口须正确参与命令通知。

## 必要行为检查

沿用现有 Smoke harness，不新建测试项目或引入包。新素材写入本次 `desktop/artifacts/` 专属目录，使用可控 runner 检查提交内容，不跑完整电影。

- 初次 SC、TC-only、SC+TC 及同槽替换保持既有默认/显式旗标语义。
- 禁用 SC/TC 后提交确实只含启用的 ASS；全禁用不可启动；启用恢复不丢属性；移除使槽位清空。
- 有效本地视频/ASS/目录、中文空格及大写扩展名接纳正确。
- 非法类型、缺失路径、重复 ASS、无效第二候选操作整体拒绝；原始路径、属性与草稿修订不变；取消分配无需调用提交接口。
- 同一路径对同槽操作无害，不能跨槽重复；批量分配必须允许整组有效替换而不错误地与将被替换的旧槽位比较。
- 运行/取消清理/关闭等待拒绝接纳；已提交 Core 快照不受后续动作影响；运行中 metadata 通过 UI 仍不可编辑。
- 任务后修改视频、字幕路径、字体/输出设置或外加元数据将结果标记为历史；选中行/切页不标记；同值赋值不产生虚假变化。
- 源探测旧结果不覆盖新视频，摘要未知字段不捏造；分组与旧 `Tracks` 一致。

执行 Release 构建与常规 Smoke，并运行新增行为入口（若单独提供）。若现有 `--warning-policy` 的 UI 展示检查受影响，执行该检查并保持全部可继续提示可见；不得修改其诊断政策。真实 UI 拖入及新布局留给 B/C，不报告为已验收。

5. 实施中发现的范围问题及建议。
