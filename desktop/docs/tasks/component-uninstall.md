# 组件目录管理与行内卸载

按用户最终确认的目录管理方案执行，不增加安装归属记录。手动复制和软件下载的组件同样归属于配置的组件目录；PATH/系统主程序不提供卸载。输入为当前检测、配置目录和用户行内确认的目标，输出为删除结果、操作日志和真实重新检测状态。

四组件只删除约定的直接子目录。AFS 主程序卸载包含其 assfontsubset/python 随包依赖，不连带删除独立 fonttools；独立依赖单独卸载，主程序保留，主程序缺失时仍能管理残留依赖。重新安装优先复用组件目录内可运行的独立依赖。

使用轻量 ⋯ 菜单和条目内确认，显示完整删除目录及“全部内容”。删除前检查边界和链接，删除中继续检查，拒绝外部、根目录、越界和目录联接/符号链接。不清理日志或配置。失败明确保留原因、日志和重试，不把部分删除宣称成功；安装与卸载共用互斥，封装/探测忙碌时不允许卸载。关闭等待已开始删除收尾。

验收包含手动副本、外部主程序、独立/随包依赖、系统回退、文件锁失败/重试、链接/越界拒绝、确认取消、路径变更导致确认失效、互斥、导航/关闭与两尺寸截图。所有删除测试只在唯一临时目录进行，不删除当前用户组件。

## 实现结果

`ComponentDirectories` 根据当前配置和固定子目录生成卸载计划，执行时重新核验，不依赖安装归属记录。`ComponentUninstaller` 负责预检、逐项删除和日志；与安装器共用 `ComponentOperations.Gate`。外部主程序不显示卸载，独立 fonttools 仍可单独管理。AFS 重装前验证已有独立依赖，验证通过直接复用；异常依赖不会被覆盖。

条目通过轻量 ⋯ 菜单打开行内确认，完整显示目标和“全部内容”；确认区自动滚入视口，初始焦点落在取消。失败原地显示原因、详情与重试，重试仍需确认。删除开始前可取消，开始后等待收尾；窗口关闭等待操作结束。封装、媒体导入和源/成品探测期间禁止卸载，卸载期间禁止启动新的工具任务；环境自有检测先取消并等待结束。操作后重新检测，允许回退到仍存在的 PATH/系统组件。
