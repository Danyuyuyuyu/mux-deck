# 全窗口拖放与右上角通知

## 用户确认范围

用户已同意统一窗口客户区拖放遮罩（包含导航，不覆盖系统标题栏），仅单个封装页面接纳，移除每个版块的高亮与临时拖入文案。复用自动媒体识别、整批提交及替换确认；详情浮层和确认窗口不能绕过。离开、松手、取消、隐藏页面与关闭清理遮罩，跨子控件不闪烁。

临时操作反馈迁到右上角单条状态胶囊，明确区分处理中、成功、信息、警告和错误，不解析中文猜类型。成功约五秒、普通反馈短暂显示，处理中保持到结束，警告/错误保持到关闭或下次操作；连续相同反馈不重复刷新，旧计时不得关闭新通知，长文本可查看全文。底部缺项、进度、结果和开始封装保留。

## 输入、输出和失败

输入仍为当前本地文件集合与明确用户操作，输出为原有草稿及封装结果。此轮只改 Desktop 展示与事件宿主，不改 Core、依赖和持久化。遮罩不参与命中测试，不制造新的可落位业务；忙碌/被遮/无效输入仍拒绝且草稿保持。取消选择/确认或识别结束不得遗留“处理中”。字体目录单独接纳不显示“0 条轨道”。

## 验证

Release 构建及相关 UI/自动拖放回归；窗口侧栏和空白处悬停/落下、跨控件、离开/Drop/取消、隐藏页与忙碌、详情遮挡；通知类型、自动消失、错误关闭、重复去重、旧计时与新消息、长文本和两种窗口尺寸；底部任务状态保持。真实 Explorer/DPI 未操作时单独标明，headless 不作原生证据。

2026-10-10 已完成。窗口接线与展示位于 Desktop，未改 Core 或依赖。Release 无告警/错误；新反馈 24/24、原 UI 174/174、自动导入 25/25、工作台 38/38、旧接纳 88/88、Smoke 26/26 通过。两尺寸截图已检查，具体证据见[验证记录](../agents/verification.md#全窗口输入反馈2026-10-10)。原生 Explorer/DPI 未人工验证。
