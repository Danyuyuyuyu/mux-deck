# 已确认的单个封装布局基线

确认日期：2026-10-10。用户指示：“ui暂时按照三张布局稿中的做”。本目录保存确认时的三张原型图，避免只引用被 Git 忽略的 artifacts。原型代码仍位于本机 `desktop/artifacts/inspector-layout-prototype/`，不直接移植为生产实现。

后续更新：同日用户的新红框将右侧轨道属性面板改为贴窗口客户区右边与上下边缘的 300 宽全高栏，见 [全高属性栏任务](../../tasks/full-height-track-sidebar.md)。本目录 `track.png` 的 320 宽、止于状态栏上缘几何作为历史参考；普通页与结果详情布局继续沿用。

- [普通封装](normal.png)：紧凑摘要、统一轨道表、字体/输出设置与固定状态区。
- [轨道属性打开](track.png)：320 宽右侧 Overlay，主页面不重排，底部操作保持可见。
- [结果详情打开](result.png)：300 高底部 Overlay，位于固定状态栏上缘，主页面不重排。

图像为 1040×760 应用内容区，不计系统标题栏。主内容宽 828，保留当前 172 宽侧栏与左右各 20 留白；视频摘要约 72 高、内容清单约 312 高、设置约 118 高、状态约 76 高。原型普通场景为 3 条源轨与 2 条外加字幕；多轨在清单内部滚动。

这些是视觉、空间和交互基线。电影名、语言、媒体信息、附件数、结果与 QC 都是示意，生产 UI 必须用真实探测/请求/结果。源轨固定策略保持；右侧和底部暂一次显示一个，动画、拖拽调高及双面板共存尚未确定。

实施范围、数据限制和验收以 [布局落地任务](../../tasks/single-mux-ui-approved-layout.md) 为准。原生 Avalonia 字体/控件几何与 DPI 必须另行复核，不以 PNG 或 HTML 测量宣称通过。
