# v2 浅色视觉规范

## 范围与文件归属

应用固定使用浅色 Fluent 主题；原生模板负责复选框、菜单、滚动条及焦点反馈。当前不增加主题切换或暗色资源。

- `src/MuxDeck.Desktop/Styles/Resources.axaml` 是颜色、字体、通用尺寸、圆角和面板阴影的唯一值来源。品牌色同时供 Fluent palette 与应用主操作使用。
- `Styles/Controls.axaml` 管理窗口、弹窗、文字角色、内容面、按钮、输入框、下拉框与页签的共享样式。
- `App.axaml` 只装配主题、资源与共享样式。
- `Views` 保留页面结构、轨道行、拖入和 Overlay 专属样式；`ViewModels` 和 Core 的职责不变。代码创建的窗口使用 `dialog` 类，接入同一套样式。

## 颜色与层级

工作区浅灰、侧栏略深、内容面与详情面板白色。主文字深灰，说明和路径中性灰；蓝色用于主操作、选中与焦点。导航选中背景、轨道选中背景、拖入背景各有语义资源，不以同一资源耦合不同反馈。

绿色表示成功校验；褐色表示结果提示；红色表示失败与移除操作。颜色附带可见文字，不能用颜色替代状态或真实结果。取消、历史结果和失败仍使用现有明确文案，不按日志猜测业务状态。

单个封装采用平面工作台：大区用标题、间距和极浅分隔线区分，不以完整圆角卡片包裹。输入框、按钮、菜单、表头和详情面板保留必要边界与局部 Surface；仅 Overlay 使用轻阴影。其他页面的共享 panel 样式保留。

## 文字与尺寸

字体使用 Microsoft YaHei UI / Segoe UI；开发日志使用 Consolas 并保留中文回退。

| 用途 | 字号 |
|---|---|
| 说明、路径、表格、字段标签 | 12 |
| 正文、操作、状态摘要 | 13 |
| 分区标题、页签 | 14 |
| 详情面板标题 | 16 |
| 独立页标题 | 18 |
| 当前视频文件名 | 16 |
| 品牌 | 20 |
| 页面标题 | 22 |

标题与分组使用 SemiBold，正文使用常规字重。页面文字统一引用字号资源，不继续增加 10/11/15/17 等零散规格。

通用控件最小高 32，紧凑按钮最小高 28；控件圆角 4，内容面圆角 6，内容面默认内边距 12。页面使用已有 4/6/8/10/12/16/20 的紧凑空间预算，不通过扩大所有间距改变最小窗口行为。

## 控件状态

- 主操作蓝底白字，悬停与按下逐级加深；次操作白底细边框；轻操作透明背景、中性文字；危险操作使用红字与浅红交互背景。
- 普通按钮、关闭与更多图标的内容水平/垂直居中，页签内容居中；侧栏导航保留左对齐，轨道行保留列布局。表头与源/外加行共享八列：无文字纳入列、ID、类型、语言、名称、默认、强制、编码。类型色点只辅助扫描，文字不可省略；空名称留空；旗标开启用 ✓，关闭及未声明为空白，未知语义保留在 Tooltip。单行输入与下拉框垂直居中；多行路径、错误和日志保持顶部阅读。
- 禁用按钮使用浅灰底与灰字，轻操作禁用保持透明背景。
- 可编辑输入框白底；只读输入框浅灰底且仍可聚焦、选取与复制；禁用输入使用独立灰色背景。只读不等于禁用。
- 轨道选中使用浅蓝背景和蓝色左标记；悬停使用浅灰。行按钮模板保持透明，不能遮盖外层行状态。
- 轨道行按钮铺满 32 高整行（含上下空白、纳入列空白与左侧标记），不使用按压位移、缩放或过渡。可编辑复选框位于独立上层，只切换包含状态；只读复选框区域由行按钮响应查看属性。
- 页签、复选框与菜单复用 Fluent 模板和同一品牌色，保留原生键盘交互与焦点指示。

## 布局与验收

单个封装以 [工作台重构任务](../tasks/single-mux-workbench.md) 为最新范围。进入后直接显示封装/字体附件/可选日志页签、文件摘要、轨道与内容、输出设置和 Action Bar；左侧导航已表达页面位置，不再传入或显示重复标题。右侧属性栏继续 300 宽全高覆盖，贴客户区边缘；展开不重排主区，覆盖到的操作退出鼠标与 Tab，关闭/Esc 后恢复。

默认列宽下普通 3 源轨 + SC/TC 在 1040×760 不需整体滚动；多轨在清单垂直滚动，手动加宽列后在表格内部水平滚动，表头同步偏移。列边界平时隐藏，Hover/键盘焦点显示轻引导，拖动增强；支持拖动、左右键调整、Home/双击恢复单列及表头菜单恢复全部。列宽采用 DIP，自动记住，无手动保存入口。名称列默认弹性，手动调整后固定，恢复默认后重新填充。

外加行从旧到新连续显示数字 ID，与旧草稿 SC/TC 槽位、音频文件内 Track ID 和成品 Track ID 区分；同槽替换保留顺序，移除再添加排末尾。源轨组锁定标识与 Tooltip 说明固定策略；主表不会开放源轨编辑。

输出设置为平面 Section，目录选择保留，打开和清空收入菜单，不恢复输入路径复制。字体辅助文案放在字体路径附近，只声明开始时检查。底部 Action Bar 固定，开始/重试/再次封装为唯一显著主操作；实际检查、错误、警告、取消、历史结果和阶段进度继续由真实状态投影。

两个详情面板仍互斥；切页/切 Tab 隐藏属性栏并保留状态。发布版日志策略仍沿用现有开发开关，本轮不作发布决定。

构建与 UI 检查按 [验证要求](../agents/verification.md)执行。headless 截图验证布局与应用控件；原生选择器、标题栏、125%/150% DPI、系统剪贴板及辅助技术保留人工检查。

自动拖放最新范围见 [自动识别任务](../tasks/automatic-media-drop.md)：无论文件落在视频、轨道、字体区还是工作区空白，都按实际类型落位；详情浮层阻止穿透。多字幕与外加音频仍使用同一表格和编号系统，类型色点/名称/语言/旗标语义不变。无 ASS 时字体辅助说明为“仅 ASS 字幕需要字体目录”，不把未执行检查绘制为成功。

拖入与通知反馈按[窗口反馈任务](../tasks/window-input-feedback.md)：不再给视频/轨道/字体区分别高亮或插入提示。拖入时统一浅蓝透明遮罩、外围虚线、中央图标和说明，覆盖客户区含侧栏；拒绝时用警告语义和原因，遮罩不阻挡指针。临时操作采用右上角单条通知胶囊，图标与文字共同表达类型；局部 Surface 复用主题语义 Token，长文本截断并用 Tooltip 补全。属性栏打开时通知避让，不覆盖关闭入口。底部持续保留准备状态、缺项、进度、结果及主要操作。
