# v2 浅色视觉规范

## 范围与文件归属

应用固定使用浅色 Fluent 主题；原生模板负责复选框、菜单、滚动条及焦点反馈。当前不增加主题切换或暗色资源。

- `src/MuxDeck.Desktop/Styles/Resources.axaml` 是颜色、字体、通用尺寸、圆角和面板阴影的唯一值来源。品牌色同时供 Fluent palette 与应用主操作使用。
- `Styles/Controls.axaml` 管理窗口、弹窗、文字角色、内容面、按钮、输入框、下拉框与页签的共享样式。
- `App.axaml` 只装配主题、资源与共享样式。
- `Views` 保留页面结构、轨道行、拖入和 Overlay 专属样式；`ViewModels` 和 Core 的职责不变。代码创建的窗口使用 `dialog` 类，接入同一套样式。

## 颜色与层级

工作区浅灰、侧栏略深、内容面与详情面板白色。主文字深灰，说明和路径中性灰；蓝色用于主操作、选中与焦点。导航选中背景、轨道选中背景、拖入背景各有语义资源，不以同一资源耦合不同反馈。

绿色表示成功校验；褐色表示结果提示；红色表示失败与移除操作。颜色附带可见文字，不能用颜色替代状态或真实结果。取消、历史结果和失败仍使用现有明确文案，不按日志猜测业务状态。

边框用于区分内容面和字段；仅 Overlay 使用轻阴影。普通面板不叠加阴影。

## 文字与尺寸

字体使用 Microsoft YaHei UI / Segoe UI；开发日志使用 Consolas 并保留中文回退。

| 用途 | 字号 |
|---|---|
| 说明、路径、表格、字段标签 | 12 |
| 正文、操作、状态摘要 | 13 |
| 分区标题、页签 | 14 |
| 详情面板标题 | 16 |
| 视频摘要、独立页标题 | 18 |
| 品牌 | 20 |
| 页面标题 | 22 |

标题与分组使用 SemiBold，正文使用常规字重。页面文字统一引用字号资源，不继续增加 10/11/15/17 等零散规格。

通用控件最小高 32，紧凑按钮最小高 28；控件圆角 4，内容面圆角 6，内容面默认内边距 12。页面使用已有 4/6/8/10/12/16/20 的紧凑空间预算，不通过扩大所有间距改变最小窗口行为。

## 控件状态

- 主操作蓝底白字，悬停与按下逐级加深；次操作白底细边框；轻操作透明背景、中性文字；危险操作使用红字与浅红交互背景。
- 普通按钮、关闭与更多图标的内容水平/垂直居中，页签内容居中；侧栏导航保留左对齐，轨道行保留列布局。单行输入与下拉框垂直居中；多行路径、错误和日志保持顶部阅读。
- 禁用按钮使用浅灰底与灰字，轻操作禁用保持透明背景。
- 可编辑输入框白底；只读输入框浅灰底且仍可聚焦、选取与复制；禁用输入使用独立灰色背景。只读不等于禁用。
- 轨道选中使用浅蓝背景和蓝色左标记；悬停使用浅灰。行按钮模板保持透明，不能遮盖外层行状态。
- 轨道行按钮铺满 32 高整行（含上下空白、包含列空白与左侧标记），不使用按压位移、缩放或过渡。可编辑复选框位于独立上层，只切换包含状态；只读复选框区域由行按钮响应查看属性。
- 页签、复选框与菜单复用 Fluent 模板和同一品牌色，保留原生键盘交互与焦点指示。

## 布局与验收

单个封装主内容与底部结果详情沿用 [布局基线](single-mux-1040x760/README.md)。右侧轨道属性栏按 2026-10-10 最新红框更新为 300 宽全高覆盖栏，贴客户区右边与上下边缘，只有左侧分隔线，无圆角/外侧留白；标题与操作固定，中间单独滚动。展开不重排主内容，覆盖到的右侧状态操作退出 Tab 与鼠标命中，关闭/Esc 后恢复。

普通 3 源轨 + SC/TC 在 1040×760 不需要整页滚动，多轨仅清单滚动；属性栏关闭时字体/输出设置与固定主操作同时可达。两个详情面板互斥；切页或切到字体/日志页签时属性栏隐藏，返回封装页恢复已有选择与面板状态。实施范围见 [全高属性栏任务](../tasks/full-height-track-sidebar.md)。

字号整理允许面板按实际文字略增高度；不得压缩轨道清单到普通场景必须滚动，不得遮挡主操作或回退窗口级键盘导航。

构建与 UI 检查按 [验证要求](../agents/verification.md)执行。headless 截图验证布局与应用控件；原生选择器、标题栏、125%/150% DPI、系统剪贴板及辅助技术保留人工检查。
