# Mux Deck v2 开发约定

## 适用范围

本文件及 `docs/agents/` 只约束 `desktop/` 下的 C#/.NET/Avalonia 新版。仓库外层的 Python/Web 代码属于 v1，作为业务参考；v1 的架构冻结约束不作为 v2 的代码骨架。

新版从单个封装开始，先完成字体子集化与封装的真实闭环，稳定后复用到批量封装，再增加其他功能。已有窗口和导航是开发骨架，功能完成以对应阶段验收为准。

## 按任务读取

- **代码变更**：在新增、修改、移动或删除代码前，读取 [代码骨架](docs/agents/skeleton.md)，确定职责、依赖和文件归属。
- **功能开发**：读取 [开发流程](docs/agents/migration.md)，确认当前阶段、输入输出、范围和完成条件；涉及旧版行为时核对对应旧代码。
- **验证与交付**：读取 [验证要求](docs/agents/verification.md)，按改动选择检查并记录结果。
- **工具诊断**：解析、修改或验收外部工具输出、告警或失败策略时，读取 [工具诊断分类](docs/agents/diagnostics.md)；该文档维护唯一分类白名单与未知诊断策略。
- **运行与依赖**：命令见 [README](README.md)；SDK、框架和包版本以项目配置及锁文件为准。

## 工作约定

- 每次开发先写清本次输入、输出、失败行为和验收场景，再实现该范围内的完整流程。长期规则放在对应规范；阶段进度放在 `migration.md`。
- 新版直接执行 C# 核心流程。v1 可用于阅读和行为对照，不作为新版的 HTTP 或 Python 业务服务。
- 功能迁移区分保留行为、修正缺陷和新增能力；发现旧版缺陷时记录差异与验证依据。
- 每条规则只保留一个权威位置；改变规则时同步调整它的链接和相关实现。
- 新增或修改的代码注释使用中文，解释原因、约束和异常路径。
- 子代理按实际需要使用；需要时按用户约定选择 `gpt-6.1-sol` / `high` 或 `gpt-6-luna` / `xhigh`。任务同时说明范围、共享文件归属和验收结果。

## 完成报告

说明实际完成的能力、执行的验证和仍未覆盖的场景。真实工具链尚未通过时，明确标为未验收；窗口可显示和代码可构建不代表封装能力已完成。
